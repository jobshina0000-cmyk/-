# 24の強み診断ツール

ポジティブサイコロジーの考え方をもとにした、
「24の強み」を整理・可視化するためのセルフチェックツールです。

就労移行支援事業所等での自己理解支援や、
強み整理ワークを目的として作成しています。

---

## 概要

本ツールは、利用者が質問に回答することで、
自身の強み傾向を確認できるHTMLベースの診断ツールです。

従来使用していたVIA診断では、
アカウント登録や英語表記等のハードルがあったため、
より簡単に実施できるよう独自ツールとして作成しました。

---

## 特徴

- ブラウザのみで動作
- インストール不要
- スマホ・PC対応
- データ保存なし
- 個人情報入力不要
- URLを開くだけで利用可能

---

## 利用方法

1. URLを開く
2. 質問に回答する
3. 診断結果を確認する

必要に応じて、
結果画面を印刷・PDF保存してご利用ください。

---

## データについて

本ツールはサーバーへのデータ送信・保存を行いません。

入力内容や診断結果は、
利用者のブラウザ上でのみ処理されます。

※ブラウザの履歴やキャッシュ等は、
利用端末側に保存される場合があります。

---

## 注意事項

- 本ツールは医療診断を目的としたものではありません。
- 自己理解・強み整理の補助ツールとしてご利用ください。
- 結果は固定的な性格診断ではなく、
  状況や経験によって変化する可能性があります。
